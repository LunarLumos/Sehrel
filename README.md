# Sehrel - Dhaka Ramadan Calendar 2026

**Sehrel** is an online Ramadan timing application for **Dhaka, Bangladesh**. The app allows users to easily view **daily Sehri and Iftar times**, highlighting **today’s schedule**, with a **cute, aesthetic, and user-friendly interface**.

**Made by LunarLabs**

Visit the app here: [Sehrel](https://your-website-link.com)

## Features
- Accurate Sehri and Iftar times for Dhaka.
- Automatic adjustment: Sehri (-1 min) & Iftar (+1 min) for safety.
- Highlights today’s schedule dynamically.
- Cute and modern UI with aesthetic design.
- Mobile-friendly and responsive layout.
